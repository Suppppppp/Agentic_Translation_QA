# 시스템 개선 비교 문서

이 폴더는 Agentic Translation QA 시스템을 한 번에 완성된 결과로 설명하지 않고,
동일한 기준선 위에서 개선 과정을 누적 기록하기 위한 공간이다.

## 이후 문서 작성 규칙

개선 실험 문서는 `02_...`, `03_...`처럼 시간 순서로 추가한다. 기존 문서와
산출물은 덮어쓰지 않는다.

각 문서에는 다음 항목을 포함한다.

1. 변경 가설과 실제 변경 범위
2. 변경하지 않은 모델·데이터·glossary·실행 조건
3. 사용한 artifact와 설정의 ID 및 SHA-256
4. 개선 전·후 지표의 분자와 분모
5. 동일 사례에서 오류가 해결·유지·악화됐는지 비교
6. latency, retry, component failure 등 품질 외 비용
7. 채택·보류·폐기 결정과 그 근거

## 비교 해석 원칙

- 40문장 4-way benchmark의 자동 지표와, 일부 문장만 사람이 검수한 Agent
  판단 지표를 같은 모집단의 수치처럼 합치지 않는다.
- 행동 기준으로 선정한 수동 검수 배치는 전체 benchmark를 대표하는 무작위
  표본이 아니다. 문서에는 항상 선정 목적과 표본 수를 함께 적는다.
- 정확도, recall, 성공적 수정률은 백분율만 적지 않고 분자/분모를 병기한다.
- 동일한 입력을 비교하지 않은 결과는 개선 효과의 인과 근거로 사용하지 않는다.
- 개선 뒤 전체 benchmark를 다시 실행하더라도 이전 artifact는 보존하고 새 run
  ID로 기록한다.
- 부정적 결과와 regression도 성공 사례와 동일하게 남긴다.
